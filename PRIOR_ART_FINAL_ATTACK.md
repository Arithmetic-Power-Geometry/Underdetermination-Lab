# Final Prior-Art Attack and Defensible Claim Boundary

Copyright (C) 2026 Mohammad Amir Khusru Akhtar

## Question under attack

> Given finite evidence K, construct the worlds still statistically admissible under K. If those worlds imply mutually incompatible downstream decisions, find the cheapest admissible experiment that can resolve the disagreement at the declared reliability; otherwise return a typed obstruction or abstention certificate.

This document is a claim-control artifact, not a novelty declaration.

## Closest prior-art families

### 1. Decision Region Determination / Equivalence Class Determination
DRD and ECD already formulate target-aware information gathering: reduce a supplied hypothesis/version space only far enough to identify a decision/equivalence class while minimizing test cost. Therefore minimum-cost target identification over a supplied finite hypothesis set is NOT a novel claim here.

### 2. Noisy Bayesian active learning
EC2/ECED-style work already handles noisy tests and target/equivalence-class identification. Therefore noisy observations, unequal test costs, and decision-aware acquisition are NOT individually novel.

### 3. Decision-focused sequential experimental design
Recent work maintains a confidence set of predictors and selects experiments from disagreement/decision-relevant uncertainty. Therefore `confidence set + disagreement + sequential experiment selection` is NOT a novel combination by itself.

### 4. Robust/ambiguity-set optimal experimental design
Robust OED already optimizes experimental criteria over ambiguity sets. Therefore optimizing an experiment under set-valued uncertainty is NOT novel by itself.

### 5. Obstruction-aware finite identification
Recent executable work explicitly computes exact minimum remaining identification cost over finite supplied world tables and can return target-distinct obstruction pairs. Therefore `minimum cost + target worlds + obstruction` over an externally supplied finite deterministic world set is NOT novel here.

## Surviving boundary to test

The potentially defensible contribution is the audited *interface*:

K -> C_alpha(K) -> downstream decision partition -> minimum-cost certified experiment -> typed statistical obstruction.

The important restriction is that C_alpha(K) is generated from finite noisy observations with advertised statistical admission/coverage semantics; it is not simply a user-supplied version space. The obstruction can also arise from continuous statistical non-separation at a decision boundary, rather than only from duplicate rows in a finite experiment table.

This should initially be framed as an evidence-to-planning interface/protocol. A stronger claim requires a formal separation theorem showing that the complete statistical-admission problem cannot be reduced without loss to an existing DRD/ECD or decision-focused sequential-design formulation.

## Claims prohibited in the manuscript

Do not claim as new:

1. choosing the cheapest informative experiment;
2. decision-aware rather than global information acquisition;
3. maintaining a confidence/version set;
4. disagreement-based active sampling;
5. ECD/DRD-style target identification;
6. unequal experiment costs;
7. noisy tests;
8. confidence intervals or confidence-set inversion;
9. no-margin difficulty near a continuous decision threshold;
10. returning an obstruction pair for a supplied finite world table.

## Candidate contribution statement

> We study an evidence-first interface between finite-sample statistical uncertainty and cost-aware experimental planning. Finite noisy observations are converted into a coverage-controlled admissible-world set. The downstream decision map is then evaluated over that set. If all admissible worlds agree, no additional experiment is required; if they disagree, a target-aware planner seeks the least-cost admissible experiment meeting a declared separation criterion; and if such resolution is impossible under the experiment family, margin, or budget, the procedure returns an explicit obstruction rather than an unsupported decision.

This wording deliberately does not claim that the downstream planner, confidence-set construction, or obstruction principle is independently new.

## Paper decision rule

Proceed to manuscript only if all of the following are satisfied:

- empirical/statistical coverage of C_alpha(K) is validated;
- the real ML deployment example is reproducible;
- comparison includes DRD/ECD/target-aware baselines, not only information gain;
- heterogeneous costs and noisy experiments are included;
- obstruction certificates are checked against exhaustive/analytic controls;
- all numerical claims are regenerated by one-command workflow/CI;
- manuscript novelty is restricted to the evidence-to-planning composition unless a stronger theorem is proved.

If a source is found that explicitly performs this same complete chain with frequentist finite-sample admission semantics and typed continuous/budget obstruction, narrow or stop the novelty claim rather than renaming the method.
